# Hackas — Back-end

API de uma plataforma para organização de projetos, campanhas e eventos ligados à educação.

O back-end centraliza os dados e oferece os recursos utilizados pela interface para gerenciar participantes, tarefas e documentos.

## Funcionalidades

- Cadastro e autenticação de usuários com JWT.
- Gestão de projetos e categorias.
- Solicitações de participação em projetos.
- Organização de tarefas e status.
- Comentários em tarefas.
- Gestão de documentos e upload de arquivos.
- Documentação da API com Swagger.

## Tecnologias

Python, Django, Django REST Framework, Simple JWT e drf-spectacular.
